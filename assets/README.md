# Wafflr brand assets

**Primary logo (vector):** `wafflr-mark.svg` — shrug waffle character (official).

| File | Role |
|------|------|
| `wafflr-mark.svg` | Official character mark (source of truth) |
| `brand/mark-2x2.svg` | 2×2 micro grid for animations / dense UI |
| `icon.png` | App icon 1024² (required by Expo — generate if missing) |
| `adaptive-icon.png` | Android adaptive foreground on slate-900 |
| `splash.png` | Full splash (mark + wordmark on `#0F172A`) |
| `splash-icon.png` | Splash icon master |
| `favicon.png` | Web favicon |

In-app components (`src/components/brand`):
- `WafflrMark` — shrug character
- `WafflrMark2x2` — micro grid for motion
- `WafflrWordmark` — Fredoka Bold
- `WafflrLockup` — mark + wordmark + tagline

Branding kit (project artifacts): `branding-kit.html` documents variants, safe-zone, and usage.
